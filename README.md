## Run it

```sh
python3 generate.py   # renders entry.png (needs Pillow, local use only)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is the graded entrypoint (Python 3.13, standard library only): it
copies the shipped `entry.png` to the output directory, so both graded runs
write identical bytes.
